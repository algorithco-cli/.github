## What we build

[**`algo`**](https://github.com/algorithco-cli/algo) — policy-enforced guard between CLI agents and the shell: contracts, evidence, and reversible actions by default.

## Start here

- 🚀 [`algorithco-cli/algo`](https://github.com/algorithco-cli/algo) — code, docs, and roadmap
- 💬 [Open an issue](https://github.com/algorithco-cli/.github/issues) — questions and proposals
- 🔒 [Report a vulnerability](../../security/advisories/new) — private advisory, never a public issue

## Principles

- **Secure by default** — least privilege, secret scanning, reproducible builds.
- **Reliable in production** — health checks, observability, failure-mode thinking.
- **Consistent at scale** — one source of truth for policies, workflows, and templates.
